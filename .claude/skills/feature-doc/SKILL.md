# 1. 기능별 문서 기본 규칙

- 각 패키지 별로 `docs` 폴더 내부에서 관리되며, 그 안에서 `en`, `ko` 와 같이 언어별로 폴더가 구성되어 있다.
- 각 기능별 마크다운 형식 문서가 두 폴더(`en`, `ko`)에 각각 하나씩 추가되며, 기능별 문서파일의 파일명은 동일하다.
  ```
  └─ {패키지명}/
     ├─ docs/
     │  ├─ en/
     │  │  └─ {feature}.md
     │  └─ ko/
     │  │  └─ {feature}.md
     └─ ...
  ```
- 각 문서에는 사용된 언어마다 다른 언어의 문서로 이동할 수 있는 토글 버튼이 상단에 배치된다.

# 2. 프롬프트 실행 시 규칙.

(사용자가 특정 기능의 문서 작성을 요청하면 아래와 같이 실행한다.)

- 문서의 제목은 아래와 같이 작성한다.
  - 컴포넌트인 경우: `component_{컴포넌트명(소문자로만)}.md`
  - Hook인 경우: `hook_{Hook 이름(소문자로만)}.md`
  - 유틸리티 함수인 경우: `func_{함수명(소문자로만)}.md` => 함수는 경우에 따라 파일명이 달라질 수 있음(프롬프트에서 알려줄 것임)
  - 유틸리티 타입인 경우: `type_{타입명(소문자로만)}.md`
- 문서를 작성할 때 우선 `ko` 폴더에서 한국어 문서를 먼저 작성하고 프롬프트 실행을 중지한다.
- 이후 영어 문서 작성을 요청할 때 `en` 폴더에 영어 버전 문서를 작성한다.
  - 이때, 영어 문서는 한국어 버전 문서를 그대로 번역한다.(영어버전 템플릿에 맞게)
