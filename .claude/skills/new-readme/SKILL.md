# 1. 기본 규칙

- 사용 언어별 파일 제목
  - 영어: README.md
  - 한국어: README_kr.md
- 이 두 파일들은 모두 각 프로젝트의 루트 경로에 작성한다.
  ```
  └─ {패키지명}/
     ├─ README.md
     ├─ README_kr.md
     └─ ...
  ```

# 2. 프롬프트 실행 순서

- 프롬프트 실행 요청 시 반드시 한국어 버전 문서를 먼저 작성한 후 프롬프트 실행을 종료한다.
- 이후 영어버전 문서 작성을 요청할 때 템플릿에 맞춰 영어버전 문서를 작성한다.
  - 내용 작성시 한국어문서의 내용을 그대로 번역한다.
- 영어버전 문서 작성이 완료되면, 레포지토리 최상위에 있는 README 파일에 새로운 패키지 정보를 추가한다.
  - 한국어문서의 경우: 레포지토리 최상위/README_kr.md 파일에
  - 영어문서의 경우: 레포지토리 최상위/README.md 파일에
  - 최상위 README 문서에서 제공모듈 표 맨 하단에 새로운 패키지 "README 문서 링크"와 "간단 설명", "다운로드 링크(npm)", "GitHub 링크"를 추가할 것
